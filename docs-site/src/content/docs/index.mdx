<p class="tagline">
One YAML config in git, and any machine — Ubuntu, SUSE, macOS — becomes yours.
A single static binary that runs on a box with nothing installed on it.
</p>

<div class="install-line">
```sh
curl -fsSL https://samishal1998.github.io/bedouin/install.sh | sh
```
</div>

<div class="why">
  <div>
    <h3>Nothing to install first</h3>
    <p>A static binary with zero runtime dependencies. Ansible needs a working
    Python, which is the one thing a fresh machine cannot promise.</p>
  </div>
  <div>
    <h3>One run, in order</h3>
    <p>Install a toolchain and something that needs it in the same run. Bedouin
    tracks where it put things and builds each step's environment itself
    instead of inheriting your shell's.</p>
  </div>
  <div>
    <h3>It tells you first</h3>
    <p><code>plan</code> is a faithful prediction of <code>apply</code>. Where
    it cannot be, it says so rather than guessing.</p>
  </div>
  <div>
    <h3>Your edits survive</h3>
    <p>Tweak an alias in your shell, then <code>absorb</code> it back into the
    config. Bedouin owns blocks inside your rc files, never the files.</p>
  </div>
  <div>
    <h3>Conditionals that cannot rot</h3>
    <p>A mapping means branches, and arm names come from a closed set — so a
    typo is an error, not a branch that never matches on a machine you are not
    sitting at.</p>
  </div>
  <div>
    <h3>It only removes what it installed</h3>
    <p>Anything already there when Bedouin first ran is adopted, never owned,
    and survives being dropped from the config.</p>
  </div>
  <div>
    <h3>Your shell, not just your tools</h3>
    <p>Install oh-my-zsh, set its theme and plugins — written above the line
    that reads them, because below it would do nothing at all.</p>
  </div>
  <div>
    <h3>Configs that live in git</h3>
    <p>Clone a repository, link a subdirectory of it into place. How oh-my-tmux
    installs, and how a neovim config reaches <code>~/.config/nvim</code> with
    its history intact.</p>
  </div>
</div>
